# Apresentação / Treinamento da Recepção — AutoVale Prevenções

Material de treinamento para novos funcionários de recepção aprenderem a usar os
sistemas da AutoVale no dia a dia.

## Conteúdo deste repositório

| Arquivo | Para quê |
|---------|----------|
| `prompt-para-ia-apresentacao.md` | ⭐ Prompt pronto para colar numa IA de slides (ex.: Gamma) e gerar a apresentação |
| `guia-treinamento-recepcao.md` | Guia escrito passo a passo (material de apoio detalhado) |
| `roteiro-apresentacao-15min.md` | Roteiro falado, cronometrado em ~15 min |
| `imagens/` | Capturas de tela usadas no guia e na apresentação |

## Os 3 sistemas da recepção (login único: CPF só números + senha)

1. **Sistema de Gestão** (`aeasy.autovaleprevencoes.org`) — consultar associado, ficha, boletos, acompanhar vistoria.
2. **Portal do Consultor** (`consultor.autovaleprevencoes.org`) — fazer as vendas / novas adesões.
3. **App AutoVale Consultor** (celular) — fazer a vistoria que ativa a proteção.

**Fluxo:** Vender (Portal) → associado fica *Novo* → Vistoriar (App) → setor valida → *Ativo* → Atender no dia a dia (Gestão).

## Como subir as imagens (prints de tela)

Coloque os prints na pasta `imagens/` seguindo a numeração abaixo. Veja o detalhe
em `imagens/COMO-NOMEAR.md`.

> Já estão no repositório: `print-01.png` (login do Gestão) e `print-16.png` (login do Portal),
> capturados automaticamente.
